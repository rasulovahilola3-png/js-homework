# Урок «JavaScript: первые программы»

Практическая работа по дисциплине **«Инструментальные средства разработки ПО»**.

## Что внутри

- `index.html` + `script.js` — демонстрационные мини-программы с урока (вывод в консоль, переменные, условия, циклы, функции).
- `homework/` — 3 домашних задания на JavaScript.
- `csharp/` — те же программы на C# (мост JS → C#).

## Запуск (JS)

1. Открыть любой `.html` файл в браузере (Chrome/Edge).
2. Нажать `F12` → вкладка **Console**.

## Домашние задания

| Задание | JS | C# |
|---|---|---|
| Калькулятор | `homework/calculator.js` | `csharp/Calculator.cs` |
| Таблица умножения | `homework/multiplication.js` | `csharp/Multiplication.cs` |
| Сумма чисел 1..n | `homework/sum.js` | `csharp/Sum.cs` |
